1.Open Google Sheets as an admin.
Go to Extensions >> Apps Script

2. script.google.com will open in a new tab

3. Replace the script in Code.gs with the one in this repository

4. Go to settings, enable appsscript.json

5. Come back to the Editor and replace the script in appsscript.json with the one in this repository.

6. Hit run. Grant all permissions.

7. Go back to the Sheets file and Run the appropriate report from the new "Org Adoption Reports" menu that should appear.
